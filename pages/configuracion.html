Formato de las Constancias

Personaliza como esta redactado el texto de cada constancia. Solo configuras esto una vez y todas las constancias saldran con ese formato.

Como funciona: El sistema arma el texto automaticamente con los datos del registro. Aqui solo defines como esta redactado segun el estilo de tu parroquia.
